# Proposal

## Why

Empty rooms and items currently display headings with no entries below them,
making room entry and inspection output look like an empty block rather than a
concise description of what is present.

## What Changes

- Omit `Exits:`, `Items:`, and `Creatures:` from a room view when the
  corresponding visible collection is empty.
- Omit `Actions:` from `/look at <item>` and `/examine <item>` when the item has
  no interactions.
- Preserve the existing headings, item/creature separation, ordering, IDs, and
  inspection details when entries exist.
- Add focused regression coverage for empty and populated room and item views.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `command-interface`: room inspection output must omit empty exit, item, and
  creature sections while retaining populated sections.
- `item-interactions`: item inspection must omit the action heading when an item
  has no available actions.

## Impact

The change is limited to presentation generated by
`target/controllers/room_controller.py` and focused tests under `tests/`. It
does not alter room data, item actions, permissions, command parsing,
persistence, or transport behavior.
